## Gap Assessment Methodology
1. Map current security controls to framework requirements
2. Score each control: Not Implemented / Partial / Implemented / Optimized
3. Identify highest-risk gaps (likelihood × impact, not just compliance checkbox)
4. Build remediation roadmap with owner + target date
5. Re-assess on defined cycle (quarterly/annual)
